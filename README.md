# AI Operations Assistant

A production-oriented AI Operations Assistant built using
AI-assisted software development and Vibe Coding practices.

## Current Status

Early development — project foundation.

- Python 3.12+
- FastAPI
- PostgreSQL
- Qdrant
- Redis
- Ollama
- Docker
- Pytest

- FastAPI application
- Health endpoint
- Basic API testing
